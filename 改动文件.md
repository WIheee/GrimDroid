## 1. app/src/main/kotlin/com/grimdroid/service/StellarShell.kt（新增文件）

通过 Stellar 以特权身份执行 shell 命令：

```kotlin
data class ShellResult(val success: Boolean, val output: String)

object StellarShell {
    suspend fun run(command: String): ShellResult = withContext(Dispatchers.IO) {
        try {
            if (!Stellar.pingBinder()) {
                return@withContext ShellResult(false, "Stellar 未连接")
            }
            val process = Stellar.newProcess(arrayOf("sh", "-c", command), null, null)
            val exitCode = process.waitFor()
            val output = process.inputStream.bufferedReader().use { it.readText() }
            ShellResult(exitCode == 0, output)
        } catch (t: Throwable) {
            ShellResult(false, t.message ?: "命令执行失败")
        }
    }
}
```

## 6. 主界面状态规则

- 未完成引导（`onboarding_done=false`）→ 显示引导页。
- 已完成引导且已授权（`stellar_authorized=true`）→ 正常主界面。
- 已完成引导但未授权 → 主界面顶部显示“功能受限”横幅，可随时点“去授权”。

“完成”与“跳过”都会写入 `onboarding_done=true`（引导只出现一次）。
